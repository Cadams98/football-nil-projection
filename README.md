# College Football NIL Projection

My project will estimate the potential name, image, and likeness (NIL) value of college football players using performance, position, school, playing time, and social media information.

The first version will use manually entered or sample data, a basic calculation, and a dashboard. Projections will be estimates, not verified earnings. Automatic data collection and machine learning are outside the initial scope.

## Requirements assignment

The initial requirements backlog is in [BACKLOG.md](BACKLOG.md). It includes requirement IDs, types, priorities, statuses, dependencies, and acceptance criteria. This repository contains the planning documents; implementation has not started.
